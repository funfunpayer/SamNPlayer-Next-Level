SamNPlayer 2 — Windows test build
=================================

This is a development build from the CI, not a release. It is portable:
nothing is installed and nothing outside this folder is changed, except the
settings and logs in %APPDATA%\SamNPlayer2.

Start:   SamNPlayer2.exe
Open:    drop a video or a script (.funscript, .samn) on the window,
         or start with a file:  SamNPlayer2.exe "C:\path\video.mp4"
Log:     Settings (gear, top right) -> Log, or the file
         %APPDATA%\SamNPlayer2\logs\samnplayer2.log
Remove:  delete this folder (and %APPDATA%\SamNPlayer2 for the settings).

Windows SmartScreen may warn because the build is not signed: "More info"
-> "Run anyway".
