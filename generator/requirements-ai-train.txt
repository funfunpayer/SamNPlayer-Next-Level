# Werkzeugkette fürs TRAINIEREN (ultralytics zieht u.a. PyTorch nach sich,

#   pip install -r generator/requirements-ai-train.txt
#
# Training-Gerät: train_yolo_model.py wählt mit --device auto der Reihe nach
# CUDA → MPS → DirectML → CPU. CUDA braucht ein CUDA-fähiges PyTorch
# (ultralytics-Default auf NVIDIA). DirectML unter Windows (AMD/Intel ohne
# NVIDIA-Zwang): zusätzlich `pip install torch-directml` - bewusst nicht hier
# gelistet, weil Linux/macOS es nicht brauchen und der Paketname
# Windows-spezifisch ist. CPU funktioniert immer, ist für echte Datensätze
# aber sehr langsam.
