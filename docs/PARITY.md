# SamNPlayer 0.7.0 -> SamNPlayer 2 parity inventory

**Why:** SamNPlayer 2 must do everything 0.7 does (Owner, 16 Oct 2026: an exact functional copy, better where we can). This file is the checklist; nothing may be forgotten.

**How to use it:**
- Tick an item (`- [x]`) only when SamNPlayer 2 has it **and** a test or a screenshot check covers it. Add where it lives: `→ SamN2: core/include/samn/curve_geometry.h`.
- A deliberate improvement keeps the 0.7 behaviour as the baseline and says what changed: `(better: …)`.
- Something we drop on purpose needs a decision in `DECISIONS.md`; link it here.
- Open items from the old roadmap (not in 0.7) are in `ROADMAP.md` § (b); they come along too.
