The licence (EULA)

SamNPlayer is freeware for private, non-commercial use. It is not open source. The EULA is shown once on first start and ships as EULA.txt in the download; you can read it any time in Settings → Licence. Please share the link to this site instead of re-uploading the program. Third-party components (FFmpeg, OpenCV, Wails …) keep their own licences — see THIRD_PARTY_NOTICES.txt.

Donate

SamNPlayer is financed by voluntary donations. Your donation keeps the project alive and makes new features possible. If it is useful to you, support it via Patreon or PayPal — the buttons are in the app under Settings → Support SamNPlayer (and the ♥ Donate button in the header). A donation is a gift: it does not unlock anything, the app is the same for everyone.

Had a key before?

Old SNP1 keys are no longer needed and are ignored — every build is fully unlocked.
