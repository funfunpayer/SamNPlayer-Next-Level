Getting started

Prefer the portable archive so ffmpeg ships next to the app. No system install required.

1. Download portable

Grab the latest Windows or Linux portable build from GitHub Releases (SamNPlayer-portable-*-amd64). Verify with checksums.txt in the same release.

macOS is not shipping yet — code is ready; a Mac builder and notarization are still missing.

2. Unzip and run

  • Windows: extract the zip, run the GUI next to ffmpeg / ffprobe.
  • Linux: extract the tar.gz; WebKitGTK is required for the GUI shell.

Single-file GUI builds exist for in-app updates, but they do not bundle ffmpeg. If tools are missing, use Settings → Install video tools (opt-in download).

3. First Play

  1. Open the Play tab (home).
  2. Load a .funscript or .samn — video is optional (script-alone works).
  3. Connect a device, Intiface, or Mock from the top bar / Device tab.
  4. Watch the live vibration and suction meters on the rail.

4. First Generate

  1. Open Generate, pick a local video.
  2. Mark ROI(s) or use classical auto-region — AI ROI is optional and local only.
  3. Run a backend (CSRT / flow / grid_lk). Cancel must recover cleanly if you stop mid-run.
  4. Read Quality Doctor on the rail before you trust the curve.

5. License (when you buy)
