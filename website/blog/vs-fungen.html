Honest scope vs FunGen

Different jobs. Overlap on generation — not a clone claim.

What SamNPlayer adds

  • Sam Neo 2 device runtime (BLE / Intiface / Mock) with diagnostics
  • Playback with sync, curve editor, O-markers, playlist
  • Training tab + Quality / Script Doctor
  • ~13 MB native GUI — no Electron shell

Where FunGen-class tools may still be stronger

  • Broader project / batch workflows
  • Some multi-backend tracking paths we still measure before porting
  • Tracker quality on Windows without OpenCV-linked CSRT

We compare on golden clips with numbers — we do not market “FunGen but prettier.” If a technique does not beat the current path on a fixed bench, it does not ship.
