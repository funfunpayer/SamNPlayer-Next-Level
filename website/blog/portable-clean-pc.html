Portable zip on a clean PC

No “install ffmpeg yourself” surprise. Prefer the portable archive.

Generate, audio-tempo check, frame previews, and “Make playable” need ffmpeg. We do not reimplement a full codec stack in the app — we ship a known-good binary next to the GUI in portable releases.

How resolution works

  1. Env overrides, if you set them
  2. ffmpeg beside the SamNPlayer binary (portable)
  3. User tools dir via Settings → Install video tools (opt-in)
  4. System PATH, if present

Single-file GUI builds are for in-app updates only. On a machine without ffmpeg, use the portable zip/tar or the Settings installer once.
