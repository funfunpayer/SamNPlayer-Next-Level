One local desktop app for .samn / .funscript and SVAKOM Sam Neo 2 — measured scripts, first-class device control, optional on-device AI that never writes alone.

Download portable Free · donate

Why this app

Most tools are a player or a generator — often inside a 100+ MB Electron shell. SamNPlayer keeps the full loop honest and small.

Size
~13 MB native GUI (OS webview via Wails — no bundled Chromium)
Scope
Play + create + device + stamina training in one window
AI
Optional local ONNX — AI proposes; classical tracking writes the script
Privacy
Local-only — no model in the binary, no surprise downloads, no cloud calls
Device
Sam Neo 2 first-class (BLE + Intiface + Mock) with diagnostics
Quality
Quality Doctor and Script Doctor — numbers before claims

What you get

Big video, every axis in view, one calm window. English UI.
